Welcome to RiffChart. Check these four things and you're ready to chart. You can change all of this later under Settings.

1 Clone Hero

2 Where finished songs go

Export copies each finished song here. Clone Hero plays them from this folder.

3 Folders RiffChart never changes

Your own chart collections. RiffChart can open charts from them but will never save, export or delete anything inside them.

4 What Clone Hero shows while you play

RiffChart gives each song a background, a highway and (for music videos) a video. Clone Hero only shows them when these options are on.

Clone Hero has to be closed to change these (it saves its settings when it exits). Its settings file is backed up first.
